# 3D-модель лыжника

Учебная модель Riders School: лыжник в 3D, суставы которого двигаются мышью только в пределах возможностей человека.

Открыть: https://antonio-rider-code.github.io/riders-skier-3d/

- Тяните за точки или части тела; пустое место — вращение камеры, колесо — масштаб.
- Готовые стойки и повороты: плуг, параллельный, карвинг начального уровня через плуг, карвинг, бедро на снегу, короткий с уколом.
- Поворот в динамике с ползунком фаз.
- Таблица углов суставов с отметкой предела.

Страница — один файл `index.html`. Для работы нужен интернет: three.js загружается с cdn.jsdelivr.net.
